## About Zen LM

Zen LM is a family of next-generation language models built on the Zen architecture:

| Model | Parameters | Status |
|-------|-----------|--------|
| zen-nano | 0.6B | Released |
| zen-eco | 4B | In Development |
| zen-omni | 7B multimodal | Released |
| zen-coder-flash | 31B MoE (3B active) | Flagship |
| zen-max | 671B MoE (14B active) | Released |

## Philosophy

The name "Zen" reflects an aspiration: clarity of mind, precision of action, presence in each moment.
